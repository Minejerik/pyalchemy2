Rework of an older project, terminal-based clone of Little Alchemy.


## How to run

Clone the repo
```
$ git clone https://github.com/Minejerik/pyalchemy2
```

Run the program
```
$ python3 main.py
```

Then input your profile name, to save data.

When you wish to leave, type "exit".
You can also type "reset" to reset all progress to start.
